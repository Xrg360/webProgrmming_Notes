## 1. **Introduction**
PHP functions are reusable blocks of code designed to perform specific tasks. Functions help in reducing code redundancy, improving modularity, and making code more maintainable.

- **Syntax:**
```php
function functionName(parameters) {
    // Code to be executed
}
```

- Functions can return values using the `return` keyword.

---

## 2. **Types of Functions**

### 2.1 **Built-in Functions**
PHP comes with a variety of built-in functions, such as:
- **String Functions**: `strlen()`, `str_replace()`, `substr()`
- **Array Functions**: `array_push()`, `count()`, `array_merge()`
- **Math Functions**: `abs()`, `round()`, `rand()`
  
### 2.2 **User-defined Functions**
- **Example:**
```php
function greetUser($name) {
    echo "Hello, $name!";
}
greetUser("John"); // Outputs: Hello, John!
```

---

## 3. **Function Parameters**

- Parameters are variables passed to functions.
- PHP supports both required and optional parameters (default values).
  
### 3.1 **Required Parameters:**
```php
function add($a, $b) {
    return $a + $b;
}
echo add(3, 5); // Outputs: 8
```

### 3.2 **Optional Parameters (with Default Values):**
```php
function greet($name = "Guest") {
    return "Hello, $name!";
}
echo greet(); // Outputs: Hello, Guest!
echo greet("Marina"); // Outputs: Hello, Marina!
```

---

## 4. **Return Values**

Functions can return values using the `return` keyword.
- **Example:**
```php
function multiply($a, $b) {
    return $a * $b;
}
$result = multiply(4, 6); // $result = 24
```

---

## 5. **Variable Scope**

- **Local Variables**: Defined within a function and can't be accessed outside it.
- **Global Variables**: Declared outside functions and accessed inside with `global` keyword.
  
### 5.1 **Global Keyword:**
```php
$globalVar = 10;

function testGlobal() {
    global $globalVar;
    echo $globalVar; // Outputs: 10
}
```

### 5.2 **Static Variables:**
- Retain their value across function calls.
```php
function counter() {
    static $count = 0;
    $count++;
    echo $count;
}
counter(); // Outputs: 1
counter(); // Outputs: 2
```

---

## 6. **Anonymous Functions (Closures)**

- Functions with no name, often used as callbacks.
  
```php
$greet = function($name) {
    return "Hello, $name!";
};
echo $greet("Rohit"); // Outputs: Hello, Rohit!
```

---

## 7. **Passing Arguments by Reference**

PHP allows passing arguments by reference, meaning changes to the parameter affect the original variable.
  
- **Example:**
```php
function addTen(&$num) {
    $num += 10;
}
$number = 5;
addTen($number);
echo $number; // Outputs: 15
```

---

## 8. **Recursive Functions**

Functions that call themselves to solve problems in a smaller, repetitive way.
  
- **Example:**
```php
function factorial($n) {
    if ($n <= 1) {
        return 1;
    }
    return $n * factorial($n - 1);
}
echo factorial(5); // Outputs: 120
```

---

## 9. **Best Practices**

- Keep functions short and focused on a single task.
- Use descriptive names for functions and parameters.
- Avoid side effects; prefer returning values instead of echoing directly.
- Use type declarations and return type hints where possible (PHP 7+).

```php
function addNumbers(int $a, int $b): int {
    return $a + $b;
}
```

### **Loosely Typed Function:**

A loosely typed function in PHP means that the function does not require strict data types for its arguments or return values. PHP is a loosely typed language, which means variables and function parameters are not required to have a specific data type and PHP will automatically convert types if necessary.

```php
function add($a, $b) {
    return $a + $b;
}

echo add(3, 5);         // Outputs: 8
echo add(3.5, 5.2);     // Outputs: 8.7
echo add("3", "5");     // Outputs: 8 (strings are automatically converted to integers)
```

### **Explanation:**
- The function `add()` doesn't enforce any data type for its parameters `$a` and `$b`.
- PHP will automatically handle different types (e.g., integers, floats, strings) and try to convert them to a suitable type for the operation (in this case, addition).
